# Стек проекта

- **React 19 + React DOM 19** — создание и отображение пользовательского интерфейса.
- **Vite 8 + @vitejs/plugin-react** — сервер разработки с горячим обновлением React-компонентов и сборка проекта.
- **TypeScript 7** — типизация кода приложения; включён строгий режим (`strict`).
- **CSS Modules** — стилизация компонентов с локальной областью видимости CSS-классов через встроенную поддержку Vite. Используйте файлы `*.module.css` и импортируйте их в компоненты как объект классов. Отдельный npm-пакет не требуется.
- **npm** — установка зависимостей и выполнение команд проекта; версии зависимостей зафиксированы в `package-lock.json`.

# Запуск проекта

В корневой директории проекта установите зависимости и запустите сервер разработки:

```sh
npm install
npm run dev
```

Приложение доступно по адресу http://localhost:5173. Порт `5173` закреплён в `vite.config.ts` с `strictPort: true`: если он занят, сервер завершится с ошибкой, не переключаясь на другой порт.

Для остановки сервера нажмите **Ctrl+C** в терминале, где выполнена команда `npm run dev`. Закрытие вкладки браузера не останавливает сервер.

Пользователь самостоятельно управляет сервером разработки. Не запускайте `npm run dev` без явного запроса пользователя.

Дополнительные команды:

- `npm run build` — проверка типов TypeScript и сборка приложения в `dist/`.
- `npm run preview` — локальный просмотр готовой сборки после `npm run build`.
